# q8020-cfd-ch-lbm

Quantum CFD solver for 1D Burgers equation using a variation of QLBM and Cole-Hopf linearization with quantum circuit propagators.

See the docs/ for details.

Data in support of the publication "Benchmarking Quantum Algorithms for the Burgers’ Equation based on the Lattice Boltzmann Method and the Cole-Hopf Linearization" is here: https://github.com/Q8020-CFD/q8020-cfd-experiments/tree/main/results/burgers-ch-lbm-June2026
