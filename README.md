# q8020-cfd-ch-lbm

Quantum CFD solver for 1D Burgers equation using a variation of QLBM and Cole-Hopf linearization with quantum circuit propagators.

See the docs for details:

- [IEEE QC4PDE workshop paper, Sept 2026 (PDF)](docs/IEEE_QC4PDE_QLBM_CH.pdf)
- [Overview](docs/OVERVIEW-burgers-solver.md)
- [Cole-Hopf method](docs/CH-method.md)
- [LLM-generated code details](docs/LLM-gen-DETAILS-burgers-solver.md)

- [Q8020-CFD parent org](https://github.com/Q8020-CFD) (ask to collaborate)

Data in support of the publication "Benchmarking Quantum Algorithms for the Burgers’ Equation based on the Lattice Boltzmann Method and the Cole-Hopf Linearization" is available in the [q8020-cfd-experiments repository](https://github.com/Q8020-CFD/q8020-cfd-experiments/tree/main/results/burgers-ch-lbm-June2026).
